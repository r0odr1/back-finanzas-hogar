# Finanzas Hogar — Backend

API REST del proyecto personal **Finanzas Hogar**, una aplicación para la gestión y control de las finanzas del hogar.

Este repositorio contiene exclusivamente el backend del sistema.

## Objetivo

Proporcionar una API centralizada para las diferentes interfaces de Finanzas Hogar:

- Aplicación Ionic.
- PWA.
- Aplicaciones móviles Android/iOS.
- Integración con Telegram.

## Tecnologías

- Node.js
- Express
- TypeScript
- Prisma
- PostgreSQL

## Arquitectura

La arquitectura general del sistema está planteada de la siguiente manera:

Ionic + Angular + TypeScript  
↓  
API REST — Node.js + Express + TypeScript  
↓  
Prisma  
↓  
PostgreSQL

Telegram también podrá consumir esta misma API.
